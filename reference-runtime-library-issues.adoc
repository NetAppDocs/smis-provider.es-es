= Problemas con la biblioteca de tiempo de ejecución
:allow-uri-read: 
:icons: font
:imagesdir: ./media/
:pp: &#43;&#43;


[role="lead"]
NetApp SMI-S Provider podría experimentar problemas con las bibliotecas de tiempo de ejecución en Windows. Instala el paquete redistribuible necesario de Microsoft Visual C{pp} para resolverlos.

* *Edición*
+
Se encuentran problemas con la biblioteca de tiempo de ejecución.

* *Acción Correctiva*
+
Instale Microsoft Visual C{pp} 2010 Redistributable Package (x86) desde www.microsoft.com.
